Das Wichtigste in Kürze

  • Topos hat keinen eigenen Server. Dein Inventar (Container, Einträge, Kategorien, Aktionen, Fotos) und deine Einstellungen liegen ausschließlich in deinem Browser (IndexedDB und localStorage). Der Betreiber sieht sie nicht.
  • Die App setzt keine Cookies, nutzt keine Analyse- oder Tracking-Dienste und braucht kein Konto. Schriften und Skripte sind mitgeliefert und werden nicht von Dritten geladen.
  • Beim Aufruf der Seiten verarbeitet GitHub als Hoster deine IP-Adresse. Alles andere geht nur dann an Dritte, wenn du eine Funktion nutzt, die das erfordert.

Hosting bei GitHub Pages

Die App wird von GitHub Pages ausgeliefert, einem Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Bei jedem Aufruf verarbeitet GitHub die IP-Adresse deines Geräts und die üblichen Verbindungsdaten (Zeitpunkt, aufgerufene Datei, Browsertyp) zu Sicherheitszwecken; nach Angaben von GitHub werden diese Daten nur für die Betriebssicherheit gespeichert und nicht an den Betreiber weitergegeben. Weitere Informationen: GitHub Privacy Statement.

Speicherung im Browser

Alles, was du in der App anlegst, speichert dein Browser lokal: Container, Einträge, Kategorien, Aktionen und Fotos in IndexedDB, Sprache, Design und Einstellungen in localStorage. Die Dateien der App selbst hält ein Service Worker vor, damit sie offline startet. Diese Speicherung ist für den Betrieb der App erforderlich; es wird nichts an einen Server übertragen.

API-Schlüssel für KI-Anbieter speichert die App, falls du welche hinterlegst, ebenfalls nur lokal, verschlüsselt mit einer Passphrase, die du selbst festlegst und die nicht gespeichert wird. Du entfernst sie in den Einstellungen unter „KI-Assistent“.

Dein Inventar sicherst du jederzeit unter Einstellungen › Import & Export als Datei; Fotos sind darin derzeit nicht enthalten. Einstellungen › Wartung › „Cache zurücksetzen“ löscht Container, Einträge, Kategorien und Aktionen. Entfernst du die Website-Daten in deinem Browser, sind alle genannten Daten gelöscht, auch Fotos und Schlüssel.

Update-Prüfung

Neue Versionen der Web-App lädt dein Browser über den Service Worker von GitHub Pages, also vom selben Hoster wie die App; um eine neue Version zu erkennen, ruft die App dort die Datei version.json ab. Ein anderer Dienst wird dafür nicht kontaktiert.

KI-Foto-Erkennung mit eigenem Schlüssel

Die Foto-Erkennung ist nur aktiv, wenn du in den Einstellungen einen eigenen API-Schlüssel eines Anbieters hinterlegst und die Erkennung für ein Foto auslöst. Dann sendet dein Browser das Foto, verkleinert auf höchstens 1568 Pixel Kantenlänge, zusammen mit der Art des Containers (zum Beispiel Ordner oder Box) und den Namen deiner vorhandenen Kategorien direkt an diesen Anbieter. In der Web-Version sind das Anthropic, Google oder Perplexity; OpenAI lässt Aufrufe direkt aus dem Browser nicht zu und ist nur in einer selbst betriebenen Version mit Server nutzbar. Der Betreiber von Topos ist an dieser Übermittlung nicht beteiligt und erhält keine Daten. Das Vertragsverhältnis besteht zwischen dir und dem Anbieter; es gelten dessen Datenschutzhinweise:

  • Anthropic
  • OpenAI
  • Google
  • Perplexity

Fehlerberichte über GitHub

Tritt ein Fehler auf, kannst du einen Bericht öffnen; die App zeigt ihn dir vorher vollständig an. Erst wenn du „Auf GitHub melden“ wählst, öffnet sich ein neuer Tab bei GitHub mit einem vorausgefüllten Issue (Fehlermeldung, gegebenenfalls technische Details, Browserkennung, App-Version und deine eigene Beschreibung). Gesendet wird der Bericht erst, wenn du ihn dort mit deinem GitHub-Konto abschickst; ab dann gelten die Datenschutzhinweise von GitHub. Alternativ kannst du den Bericht nur in die Zwischenablage kopieren.

Externe Links

Die App enthält Links zu externen Angeboten (GitHub, Liberapay, GitHub Sponsors, Ko-fi). Erst mit dem Klick verlässt du die App; ab dann gelten die Datenschutzhinweise des jeweiligen Anbieters. Es sind keine Skripte oder Schaltflächen dieser Anbieter eingebettet. Den QR-Code zum Teilen der App erzeugt dein Browser selbst.

Desktop-Version

Die installierte Version läuft auf deinem Gerät; deine Daten liegen dort in einer lokalen Datenbank. Der Desktop-Launcher fragt beim Start bei GitHub (api.github.com) nach, ob eine neue Version veröffentlicht wurde. Dabei erhält GitHub deine IP-Adresse; es werden keine Inhalte aus der App übertragen. Die Prüfung lässt sich in den Einstellungen des Launchers abschalten. Bei Installation und Aktualisierung lädt der Launcher den Quellcode von GitHub und die Basis-Images von Docker Hub. Die KI-Foto-Erkennung läuft dort über den lokalen Server mit dem Schlüssel, den du ihm gibst. Eine vollständige technische Aufstellung steht in der Datei PRIVACY.md im Quellcode.
