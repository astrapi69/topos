Privacy policy

Version: 17 September 2026

This policy applies to the public web version of Topos at astrapi69.github.io/topos. If you install Topos yourself (desktop launcher or Docker), you run the app on your own device or server; the operator of these pages then processes no data at all.

Controller

The short version

  • Topos has no server of its own. Your inventory (containers, entries, categories, actions, photos) and your settings live only in your browser (IndexedDB and localStorage). The operator never sees them.
  • The app sets no cookies, uses no analytics or tracking services and needs no account. Fonts and scripts ship with the app and are not loaded from third parties.
  • When you open the pages, GitHub, as the host, processes your IP address. Everything else reaches a third party only when you use a feature that needs it.

Hosting on GitHub Pages

The app is served by GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. On every request GitHub processes your device's IP address and the usual connection data (time, requested file, browser type) for security purposes; according to GitHub these data are kept only for operational security and are not passed on to the operator. More: GitHub Privacy Statement.

Storage in your browser

Everything you create in the app is stored locally by your browser: containers, entries, categories, actions and photos in IndexedDB, language, theme and settings in localStorage. A service worker keeps the app's own files so it starts offline. This storage is necessary for the app to work; nothing is sent to a server.

API keys for AI providers are, if you store any, kept locally as well, encrypted with a passphrase you choose yourself and which is never stored. You remove them in Settings under "AI assistant".

You can save your inventory as a file at any time under Settings › Import & export; photos are currently not part of that file. Settings › Maintenance › "Reset cache" deletes containers, entries, categories and actions. When you remove the site data in your browser, all of the data above is gone, photos and keys included.

Update check

Your browser receives new versions of the web app through the service worker from GitHub Pages, the same host as the app itself; to detect a new version the app requests the file version.json there. No other service is contacted for this.

AI photo recognition with your own key

Photo recognition is active only if you store your own API key for a provider in Settings and start the recognition for a photo. Your browser then sends the photo, downscaled to at most 1568 pixels on the long edge, together with the kind of container (for example folder or box) and the names of your existing categories directly to that provider. In the web version these are Anthropic, Google or Perplexity; OpenAI does not allow calls straight from the browser and can be used only in a self-hosted version with a server. The operator of Topos is not involved in this transfer and receives no data. The contract is between you and the provider; its privacy notice applies:

  • Anthropic
  • OpenAI
  • Google
  • Perplexity

Error reports via GitHub

When an error occurs you can open a report; the app shows it to you in full first. Only when you choose "Report on GitHub" does a new tab open at GitHub with a prefilled issue (error message, technical details if available, browser identification, app version and your own description). The report is sent only when you submit it there with your GitHub account; from then on GitHub's privacy notice applies. Alternatively you can just copy the report to the clipboard.

External links

The app contains links to external services (GitHub, Liberapay, GitHub Sponsors, Ko-fi). Only when you click do you leave the app; from then on the privacy notice of the respective provider applies. No scripts or buttons of these providers are embedded. The QR code for sharing the app is generated by your browser itself.

Desktop version

The installed version runs on your device; your data lives there in a local database. On start, the desktop launcher asks GitHub (api.github.com) whether a new version has been released. GitHub receives your IP address; no content from the app is sent. The check can be switched off in the launcher's settings. For installation and updates the launcher downloads the source code from GitHub and the base images from Docker Hub. AI photo recognition runs through the local server there, with the key you give it. The complete technical inventory is in the file PRIVACY.md in the source code.

Contact by email

If you write to the operator by email, your details are stored to handle the request and deleted once the request is settled and no statutory retention obligation stands in the way.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection towards the controller, and you can lodge a complaint with a data protection supervisory authority. As the operator does not hold your inventory, requests for access or erasure concerning it are addressed to your own device: Settings › Import & export or Maintenance, or the site data in your browser.

Changes

This policy is updated when the app or the legal situation changes. The date of the current version is shown at the top.
