## Archived 2026-08-12 (PWA + launcher)

Closed after the v0.2.0 audit of the two open P2 items.

- [x] PWA installability hardening. The audit measured the precache at
      2.84 MB over 79 entries and found the cause in one line:
      `globPatterns` took every emitted file. Three exclusions brought it
      to 1.62 MB - the lazy exceljs chunk (908 KB, 31%, moved to a
      CacheFirst runtime rule so offline export survives), 340 KB of
      icons nothing referenced (deleted, not just excluded), and the
      link-unfurl / install-dialog images. Manifest gained id,
      screenshots, shortcuts, maskable-192 and `orientation: any`;
      `lang` could not be dropped as planned because vite-plugin-pwa
      injects `lang: "en"` in its absence, so it names the default
      catalog instead. The install prompt left Settings > About for an
      app-level banner. Commits 9bd4dd6, ddc7302, fa681e6.

- [x] Desktop launcher build pipeline verified. The ROADMAP claimed the
      macOS and Windows jobs were unverified; they had in fact run green
      seven times each, most recently on the v0.2.0 tag. Verified from
      Linux: all three checksums, the file types, the macOS
      CFBundleVersion, and that the Linux binary starts and reports its
      version. The real gaps were elsewhere - no workflow ever executes
      what it builds (now possible via `--version`), the release
      template named a Linux asset that does not exist, and nothing told
      users that GitHub strips the executable bit. Commit 186cbec.
      Hardware start moved to Blocked / Hardware.
